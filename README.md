# Adaptive Load Control

Система адаптивного управления нагрузкой в микросервисной архитектуре с учетом приоритетов и предельных сроков выполнения запросов.

Библиотека и экспериментальный стенд для ВКР. Проект находится на начальной стадии: реализован каркас, наполнение алгоритмами и эксперименты выполняются по плану работ.

## Назначение

Механизм контроля допуска на входе Go-сервиса. Для каждого входящего запроса принимается решение: принять в обработку или отклонить до начала работы. Решение принимается по трем признакам:

1. адаптивный лимит параллелизма, пересчитываемый по изменению времени ответа;
2. приоритет запроса, передаваемый в метаданных вызова;
3. прогноз выполнимости запроса до дедлайна, взятого из context.Context.

При отклонении запрос получает быстрый отказ вместо тайм-аута. Проверка выполняется до постановки в очередь, поэтому ресурсы не тратятся на запросы, ответ на которые клиент уже не ждет.

## Текущее состояние

| Компонент | Статус |
|---|---|
| Каркас пакета limiter, интерфейс Limiter, статистика среднего времени обработки | заготовка |
| Комбинированный алгоритм: лимит, приоритет, прогноз дедлайна | заготовка |
| gRPC-интерцепторы и HTTP-мидлварь | не начато |
| Клиентская часть: бюджет ретраев, адаптивный троттлинг, ORCA | не начато |
| Экспериментальный стенд и генератор нагрузки | заготовка |
| Имитационная модель | не начато |

Сравниваемые алгоритмы (статический лимит, AIMD, Gradient, BBR-подобный) реализуют общий интерфейс Limiter, стенд и нагрузка не меняются между конфигурациями.

## Структура репозитория

    adaptive-load-control/
    go.mod                 описание модуля
    internal/limiter/      интерфейс Limiter, статистика, комбинированная реализация
    internal/middleware/   обертка обработчика поверх лимитера
    cmd/gateway/           скелет сервиса-шлюза
    cmd/loadgen/           скелет генератора нагрузки
    deploy/                docker-compose конфигурация стенда
    build/                 Dockerfile сборки

## Сборка и запуск

Требуется Go 1.25 или новее.

    go build ./...
    go test ./internal/...
    go run ./cmd/gateway -addr localhost:9090

Стенд:

    docker compose -f deploy/docker-compose.yml up --build

## Метрики эксперимента

- goodput: число успешных ответов, уложившихся в дедлайн;
- задержки p50, p95, p99;
- доля обслуженных запросов высокого приоритета;
- время восстановления после снятия всплеска;
- накладные расходы механизма на решение.
